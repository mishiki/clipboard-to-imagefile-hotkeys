クリップボードの画像を自動的に画像ファイルにしてアップロードとかできるようにしてその後自動的に消してくれるツール

クリップボード上の画像を一時PNGファイルに変換。ファイルとしてブラウザなどに貼り付ける、複数枚まとめてExplorerへ渡す等の操作を、キーボードショートカットから呼び出せます。

ZIPをダウンロード より詳細な説明・ソースコードを見る
CtrlShiftAltV

ストック済みのPNG、または現在のクリップボード画像をFileDropListとしてセットします。

Four actions

最低限の機能

Ctrl + Shift + Alt + V

ストック全件をファイルとしてセット。空なら現在の画像を単発変換。

Win + Shift + B

現在のクリップボード画像をストックへ追加。

Win + Shift + O

画像をPNG化し、Explorerで選択した状態にする。

Win + Shift + Q

常駐ユーティリティを終了。

Behavior

極小で常駐

01

ファイルとして再利用

PNGのFileDropListをクリップボードへ設定。対応アプリでは通常の貼り付け操作で扱えます。

02

複数画像をストック

画像を順に追加し最後にまとめてファイル一覧としてブラウザなどへ渡せます。

03

自動クリーンアップ

自動作成したファイルは24時間経過または100枚超えで勝手に消えていきます。

Setup

3ステップで常駐。

Windows 10 / 11 と Windows PowerShell 5.1。追加モジュールは不要です。
  1. ZIPをダウンロードして展開
    上のボタンから最新版を取得します。
  2. 展開したフォルダでPowerShellを開く
  3. インストーラーを実行 
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1

Uninstall

アンインストール

常駐プロセス解除、スタートアップ登録解除、一時PNGファイルを削除します。
  1. 展開したフォルダで実行 
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Uninstall.ps1
  2. PNGファイルを消さずに残しておきたい場合 
    .\Uninstall.ps1 -KeepTemporaryFiles
