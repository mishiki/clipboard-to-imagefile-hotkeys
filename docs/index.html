画像を、
貼れるファイルへ。

クリップボード上の画像を一時PNGに変換。ファイルとして貼り付ける、複数枚まとめる、Explorerへ渡す操作をグローバルホットキーから呼び出せます。

ZIPをダウンロード ソースを見る
CtrlShiftAltV

ストック済みのPNG、または現在のクリップボード画像をFileDropListとしてセットします。

Four actions

必要な操作だけ。

Ctrl + Shift + Alt + V

ストック全件をファイルとしてセット。空なら現在の画像を単発変換。

Win + Shift + B

現在のクリップボード画像をストックへ追加。

Win + Shift + O

画像をPNG化し、Explorerで選択した状態にする。

Win + Shift + Q

常駐ユーティリティを終了。

Behavior

静かに常駐、使う時だけ。

01

ファイルとして再利用

PNGのFileDropListをクリップボードへ設定。対応アプリでは通常の貼り付け操作で扱えます。

02

複数画像をストック

画像を順に追加し、最後にまとめてファイル一覧として渡せます。公開後にストックは消費されます。

03

自動クリーンアップ

一時PNGは24時間または100枚を基準に整理。常駐中の待機はWindowsメッセージ駆動です。

Setup

3ステップで常駐。

Windows 10 / 11 と Windows PowerShell 5.1。追加モジュールは不要です。
  1. ZIPをダウンロードして展開
    上のボタンから最新版を取得します。
  2. 展開したフォルダでPowerShellを開く
  3. インストーラーを実行 
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1

Uninstall

削除も、
明快に。

常駐プロセスを終了し、スタートアップ登録と一時PNGをまとめて削除します。設定画面を探す必要はありません。

展開したフォルダで実行

PowerShellからアンインストーラーを呼び出します。

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Uninstall.ps1

一時PNGを残す場合

.\Uninstall.ps1 -KeepTemporaryFiles
